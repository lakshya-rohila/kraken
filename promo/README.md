# Kraken launch reel

A 45 s, 1920×1080 motion-graphics reel built with [HyperFrames](https://hyperframes.heygen.com): an HTML composition rendered to MP4 frame by frame.

- `index.html` is the root timeline: 11 scenes, film grain and the music.
- `compositions/*.html` holds one scene per file. They're generated by `build_scenes.py`. Edit that script and re-run it, or edit the HTML directly. Re-running the script overwrites the HTML.
- `assets/shots/` holds real captures of the Kraken app at 3200×1800.
- `SPEC.md` is the beat-by-beat plan: 136 BPM, with the drop at 3.604 s.

## Music (not in git)

The soundtrack is a private-use edit and is never committed. `.gitignore` excludes `promo/assets/music*` and `promo/renders/`. To rebuild it, put the track at `assets/music.mp3` and loop it to 45 s on beat lines. The loop points are written in `SPEC.md`. Save the result as `assets/music-45.mp3`.

## Commands

```bash
npx hyperframes preview promo        # live preview / editor
npx hyperframes check promo          # lint + layout audit
cd promo && npx hyperframes render -q delivery -o renders/kraken-reel.mp4
```
